# Seventh Street Garage: Bolt.new starter kit

Open **BOLT_PROMPTS.md** and follow it.

- `src/data/` holds all content (services, 50 cities, FAQs, site config) as typed TypeScript. It's the source of truth.
- `src/styles/global.css` is the finished design system.
- `public/images/` holds the optimized WebP photos.
- `reference/legacy-main.js` is the original site script for Bolt to port to TypeScript.
- `package.json`, `astro.config.mjs` and `tsconfig.json` are a working Astro 5 scaffold (`npm install && npm run dev`).
